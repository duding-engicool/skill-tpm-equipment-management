# OPL 一点课（One Point Lesson）

> 本文件供技能 Agent 作为推理知识。OPL 是 TPM 中"把经验变成知识"的微型教材，一张 A4 纸讲清一个点，由员工自己编写、互相培训。

## 1. OPL 的四种类型

| 类型 | 内容 |
|------|------|
| 基础知识 | 设备/工艺/物料的基础常识 |
| 改善事例 | 某次改善的做法与效果 |
| 故障事例 | 某故障的现象·原因·对策 |
| 安全·卫生 | 危险预知、防护要点 |

## 2. OPL 标准结构

```
【标题】一句话说清这个点（如：如何快速判断xx电机异音）
【分类】基础知识 / 改善事例 / 故障事例 / 安全
【对象】适用设备/工序/岗位
【正文】
  - 现象/背景（1~2 句）
  - 要点（图文，3~5 步）
  - 正确做法 vs 错误做法（对比）
【效果】避免了什么 / 提升了多少
【编写】姓名·部门   【日期】
```

## 3. 编写引导

- 一页纸、一个点，不写长篇。
- 多用图（手绘示意/照片标注），少文字。
- 来源于现场真实事例，不抄手册。
- 编写人即培训人，写完当场 5 分钟讲给同事。

## 产物形态（本技能输出）

当用户要"OPL 模板/样例"时，输出：
- OPL 标准结构模板（填空式）
- 可按用户提供的具体事例（如某次故障）生成一份 OPL 草稿
- 企业专属（具体设备名、真实故障细节）缺失时标「待企业补充」，但结构骨架照给
