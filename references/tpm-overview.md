# TPM 全员生产维护 总览

> 本文件供技能 Agent 作为领域推理知识使用，不直接整段输出给用户；落到用户具体情境时再做解释与裁剪。

## 1. 定义与目标

**TPM（Total Productive Maintenance，全员生产维护）**：以设备综合效率（OEE）最大化为目标，以全系统的预防维修为载体，由企业全员（从最高管理者到一线操作工）参与的设备管理方法论。

**三大核心思想**
- 全效率：追求设备综合效率（OEE）最大化，而非单台设备稼动。
- 全系统：设备全生命周期（设计、制造、使用、维护、报废）都纳入管理。
- 全员：操作工、维修工、技术、管理全员参与，操作工也承担自主保全。

**TPM 的终极目标（量化）**
- 设备综合效率 OEE ≥ 85%（世界先进水平参考值；国内一般企业 60%~75% 为常见起点）
- 设备故障为零、不良为零、灾害为零（"三零"目标，方向性而非绝对值）

## 2. 八大支柱（8 Pillars）

| 支柱 | 中文 | 目的 | 主要承担 |
|------|------|------|----------|
| 1 | 自主保全（AM） | 操作工自己维护设备（清扫、点检、加油、小修） | 操作工 |
| 2 | 计划保全（PM） | 维修部门专业保全，减少故障、延长寿命 | 维修部门 |
| 3 | 个别改善（FI） | 聚焦六大损失，专题攻关提升 OEE | 跨部门小组 |
| 4 | 质量保全（QM） | 设备层面消除质量不良源 | 技术/质量 |
| 5 | 教育训练 | 提升全员设备维护技能 | 人事/培训 |
| 6 | 初期管理（MP） | 新设备/新产品的初期流动管理，从源头防缺陷 | 开发/生技 |
| 7 | 事务改善 | 间接部门效率提升，支撑制造 | 事务部门 |
| 8 | 安全卫生环境 | 零灾害、零污染 | EHS |

> 自主保全与计划保全是"两大主干"，个别改善是"突破口"。其余为支撑支柱。

## 3. 与 5S、精益的关系

- **5S 是 TPM 的基础**：没有清扫（1S）就发现不了设备微缺陷；没有整顿（2S）就做不到快速换型与目视化。通常先推 5S 再推 TPM。
- **TPM 是精益（Lean）的核心支柱之一**：精益追求"流动"，设备故障与小停是流动的最大敌人；TPM 通过消灭六大损失支撑精益。
- **TPM 与质量成本**：设备故障与不良直接产生内部失败成本；TPM 的"质量保全"支柱直击此点。

## 4. 推进阶段（一般路线）

1. 最高层宣言 + 教育培训
2. 建立推进组织（TPM 推进委员会）
3. 制定基准与方针目标
4. 支柱活动展开（先 AM，再 PM，再 FI）
5. 自主保全 7 步滚动
6. 效益核算与标准化
7. 持续评审与水平展开

> 注意：本技能不代企业做"整体 TPM 部署推进"，仅对具体模块（AM 步骤、损失分析、维保计划、点检基准等）提供产物与轻量引导。整体推进请结合企业实际。
