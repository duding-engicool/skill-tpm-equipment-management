# 计划保全（Planned Maintenance, PM）

> 本文件供技能 Agent 作为推理知识。PM 是维修部门的专业保全体系，与 AM（操作工）互补，目标是"故障为零、寿命最长化"。

## 1. 三种保全方式

| 方式 | 说明 | 适用 |
|------|------|------|
| 事后保全（BM） | 坏了再修 | 非关键、低风险、备件廉价设备 |
| 定期保全（TBM） | 按时间/产量周期更换/检修 | 磨损可预测、有寿命基准的设备 |
| 预知保全（CBM） | 依状态监测（振动/温度/油液）判断 | 关键、高价值、停机损失大设备 |

> 现代 PM 趋势：从事后 → 定期 → 预知，逐步前移。

## 2. 计划保全推进阶梯

1. 设备现状把握（故障履历、MTBF/MTTR）
2. 薄弱环节识别（高故障、长停机设备清单）
3. 定期保全体系建立（基准周期、备件策略）
4. 预知保全导入（监测手段、判定阈值）
5. 维修技能提升与备件优化
6. 与 AM 接口闭环（操作工发现→维修诊断→标准固化）

## 3. 年度 / 月度维保计划框架

**年度计划**：设备分级（A/B/C 关键度）→ A 类全年定期大修/项修排程 → 备件与预算概算。
**月度计划**：将年度拆到月，结合生产计划排停机窗口 → 工单派发 → 执行记录 → 验证闭环。

## 产物形态（本技能输出）

当用户要"维保计划"时，输出：
- 年度维保计划模板（设备/等级/保全方式/周期/预计停机/责任）
- 或月度维保计划模板（周次/设备/项目/工时/配合部门）
- 设备分级依据（A 类：停机损失大/不可替代；C 类：可事后）
- 企业专属（设备清单、等级、历史 MTBF）缺失时标「待企业补充」
